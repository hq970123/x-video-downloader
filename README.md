# X 视频下载器 v0.8.2

一个基于 Chrome Manifest V3 的 X/Twitter 公共视频下载扩展。

## 功能

- 在包含视频的 X/Twitter 帖子操作栏中显示蓝色“下载”按钮
- 自动获取 X 提供的 MP4 清晰度并选择下载
- 支持最高画质、多视频批量下载和 GIF 视频
- 支持复制 MP4 视频链接
- 显示下载进度和完成状态
- 本地保存最近下载记录，并支持重复下载提醒
- 支持 X 的 SPA 页面切换、时间线和帖子详情页
- 中文界面，支持浏览器深色/浅色模式

## 安装

1. 下载或 Clone 本仓库。
2. 打开 `chrome://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本项目根目录。
6. 刷新已经打开的 X/Twitter 页面。

## 隐私

设置和已完成下载记录仅保存在 Chrome 本地。扩展不会上传浏览历史、账号凭据或下载的视频文件。Host 权限仅限 X/Twitter 页面和下载流程使用的 `video.twimg.com`。

请仅下载你有权保存和使用的媒体内容。
